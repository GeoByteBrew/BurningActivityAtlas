# Outputs of the world run (2003–2025, run of 2026-11-15)

`world_multiyear/reports/harmonization_report.md`: validation report · `world_multiyear/csv/`: the tables
behind it · `world_multiyear/figures/`: plots drawn from those tables.

AI use: these files are produced by the project pipeline, whose code was written with the assistance of a
large language model (Claude, Anthropic). Every number is computed from NASA FIRMS data; none is produced
by a generative model, and the figures are ordinary plots, not AI-generated images. See [AI_USE.md](../AI_USE.md).
